PROJECT TITLE: Mini RAG-Based AI Chatbot

Developed By: Nikhil Singh

PROJECT DESCRIPTION:
This project is a Mini RAG-Based AI Chatbot that answers questions from uploaded PDF documents.

TECHNOLOGIES USED:
1. Python
2. Streamlit
3. Ollama
4. Llama 3.2
5. Sentence Transformers
6. FAISS
7. PyPDF

WORKING:
1. User uploads a PDF document.
2. The system extracts text from the PDF.
3. Text is divided into smaller chunks.
4. Sentence Transformers generate embeddings.
5. FAISS retrieves relevant information.
6. Ollama Llama 3.2 generates answers using retrieved context.

FEATURES:
- PDF document upload
- Question answering
- Context-based responses
- Local AI model
- User-friendly interface

CONCLUSION:
This project demonstrates how Retrieval-Augmented Generation (RAG) can provide answers from uploaded documents.
